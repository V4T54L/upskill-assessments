# progress

`ledger.md` is append-only and spans every domain in this repository. Newest entry last. Never
edit or delete a past entry — if it turns out to be wrong, append a correction that says so and
why.

An entry is worth writing only if it carries a number that was **measured**. "Got the loop
working" is not a progress entry. "Six-step run, 21,400 input tokens billed, 47s wall-clock,
model `<id>`, 2026-08-23" is.

The append-only rule is doing real work: a ledger that can be tidied retroactively converges on
a flattering story, and the failures are the part worth keeping.
